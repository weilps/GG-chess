# GG Chess

Application locale d’analyse et d’entraînement aux échecs, en français et en anglais.

Le produit sera construit par petites étapes validées avec la boucle Finn (`spec` → `build` → `review`). Il vise d’abord l’analyse après-partie de fichiers PGN avec Stockfish et un entraîneur local personnalisé.

## Inspiration

GG Chess est un projet neuf, inspiré notamment par [En Croissant](https://github.com/franciscoBSalgueiro/en-croissant), sans reprise de son code à ce stade. En Croissant est un logiciel libre sous licence GPL-3.0.

## Statut

Spécification du premier MVP en cours. Aucun moteur ne doit être utilisé pendant une partie compétitive en cours.
